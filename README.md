# MBA Teaching Portfolio · Dr. Akash Garg

Live site: https://kashee12345.github.io/mba-teaching-portfolio/

A complete online course hub for **Positive Leadership & Organizational Behavior** (10-week quarter):

- **The Boardroom Chase (start here):** 100-question MBA review game across leadership, strategy, finance and marketing
- **Course:** outcomes, assessment plan and ten fully built weeks (mini-lectures, diagrams, self-checks, discussions, rubrics, checklists)
- **Companion text:** *Leading With Purpose*, 10 chapters, 46,000+ words, 41 original diagrams
- **Flashcards:** 219 terms with study, quiz and browse modes
- **Study guides:** ten printable chapter guides with practice questions and answers
- **Leadership Lab:** six self-checking interactives (Herzberg, Tuckman, Kotter, Schein, organizational justice, PERMA audit)
- **Summit Wellness Collective:** branching leadership case simulation
- **Practice Economics Lab:** break-even, lifetime value, NPV and IRR with the math shown

Static HTML, no build step. All organizations and scenarios are fictional.
